# ChatGPT 개념 학습 프로젝트 연결 지침

사용자가 기존 프로젝트 지침을 간소화하거나 새 채팅에 적용할 기본 규칙을 요청했을 때만 제시하는 **복사 가능한 예시**다. 현재 계정의 프로젝트 설정이나 저장된 자료를 자동 변경하지 않는다.

## 최소 연결 지침 예시

> 이 프로젝트에서는 Spring·Database·Java·JPA·Security 등의 **확정된 과목별 로드맵을 따라 한 주제씩 순서대로 학습**한다. 사용 가능한 경우 `concept-learning` 스킬의 강사형 교수법·자료·코드 해설 규칙을 적용한다. `학습 시작`은 해당 로드맵 첫 주제 강의, `이어서`는 확인 가능한 현재 학습 위치에서 재개, `다음 주제`는 명시적인 진도 이동으로 해석한다. 강의 도중 질문은 현재 주제에서 심화하고, 사용자 요청 없이 다음 주제로 넘어가지 않는다. 로드맵·진도는 이 프로젝트의 최신 확정 자료를 사용하며, 접근할 수 없으면 임의로 만들어내지 않는다. 실습·퀴즈·학습 노트 저장도 자동 수행하지 않는다.

## 사용 방법과 한계

- 플러그인 설치·프로젝트 지침·진도 정보는 서로 다른 계층이다. `concept-learning`이라는 이름을 프로젝트 지침에 적는 것만으로 모든 채팅에서 스킬이 반드시 실행되지는 않는다.
- 새 채팅에서 명시적 호출이 가능한 클라이언트라면 `$concept-learning Spring 로드맵 학습 시작하자`, `$concept-learning Database 로드맵 이어서 진행해`처럼 **과목과 진행 방식**을 요청하는 것이 기본이다. 특정 개념 질문은 보조적으로 지원한다. 실제 호출 UI와 설치 여부는 클라이언트에서 확인한다.
- 기존 세션의 첨부 PDF와 학습 진도를 스킬이 자동으로 불러온다고 약속하지 않는다. 필요한 최신 로드맵은 프로젝트 파일/지침 또는 사용자가 제공한 접근 가능한 원본을 따른다.
- 강의 로드맵을 스킬 파일에 옮기지 않는다. 학습 방식은 이 스킬에서 관리하고 교재·회차·완료 위치는 별도로 관리한다.
- 현재 프로젝트 지침을 자동으로 변경하거나 새 규칙을 저장·병합하지 않는다.
