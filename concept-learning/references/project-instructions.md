# ChatGPT 개념 학습 프로젝트 연결 지침

사용자가 기존 프로젝트 지침을 간소화하거나 새 채팅에 적용할 기본 규칙을 요청했을 때만 제시하는 **복사 가능한 예시**다. 현재 계정의 프로젝트 설정이나 저장된 자료를 자동 변경하지 않는다.

## 최소 연결 지침 예시

> 이 프로젝트는 Java/Spring 백엔드 및 관련 기술의 원리와 실제 동작을 학습하는 공간이다. 개념 설명에는 사용 가능한 경우 `concept-learning` 스킬의 강사형 교수법·자료·코드 해설 규칙을 적용한다. 현재 학습 주제와 진도는 이 프로젝트의 최신 확정 로드맵, 첨부 자료, 사용자 지시를 기준으로 판단한다. 사용자가 요청하지 않은 실습·퀴즈·진도 이동·학습 노트 저장을 수행하지 않는다. 스킬이 선택되거나 자료가 접근 가능하다고 추정하지 않는다.

## 사용 방법과 한계

- 플러그인 설치·프로젝트 지침·진도 정보는 서로 다른 계층이다. `concept-learning`이라는 이름을 프로젝트 지침에 적는 것만으로 모든 채팅에서 스킬이 반드시 실행되지는 않는다.
- 새 채팅에서 명시적 호출이 가능한 클라이언트라면 `$concept-learning Java 다형성의 실제 메서드 호출 원리를 설명해줘.`처럼 시작할 수 있다. 실제 호출 UI와 설치 여부는 클라이언트에서 확인한다.
- 기존 세션의 첨부 PDF와 학습 진도를 스킬이 자동으로 불러온다고 약속하지 않는다. 필요한 최신 로드맵은 프로젝트 파일/지침 또는 사용자가 제공한 접근 가능한 원본을 따른다.
- 강의 로드맵을 스킬 파일에 옮기지 않는다. 학습 방식은 이 스킬에서 관리하고 교재·회차·완료 위치는 별도로 관리한다.
- 현재 프로젝트 지침을 자동으로 변경하거나 새 규칙을 저장·병합하지 않는다.
