# Reverse Engineering / CS Learning Visualization v0.2.0 검증

기준 소스: main `cbf82bdccbbe7f85903a43f6cb111877fcfad8be`. 두 스킬과 관련 패키징·검사만 변경한다. 다른 스킬 본문은 변경하지 않는다.

## 요구와 반영

- Reverse Engineering: 프로젝트 전체 지도·해체 분석, 취준생 눈높이의 코드/내부 원리 설명, Wiki 결정 대조, 설계 이유와 대안의 증거 구분, 포트폴리오 후보 심화 및 기여·성과 과장 방지.
- CS Learning Visualization: TCP ACK 전 범위 밖 상태 교정, 화면 레이블/메타데이터 일치 검사, 설치 패키지에 품질 기준과 임의 SVG 검사기 포함, 한국어/영어·미리보기/SVG/PNG·대상 환경·일괄 QA 규칙.
- 두 패키지 버전 0.2.0. 공통 SVG 검사기는 선택적 로컬 도구이며 자동 실행 후크가 아니다. Claude용 플러그인 카탈로그는 추가하지 않았다.

## 로컬 검증

- `package_plugins.py --check`: 6개 패키지 원본/배포본 일치.
- `check_learning_visuals.py`: Heap/Java/TCP 3개 예제, 갤러리 통과. TCP 레이블과 상태의 일치도 확인.
- `test_plugin_security.py`: 기존 악성 SVG·경로 이탈·심볼릭 링크 방어 테스트 통과.
- `test_svg_validator.py`: 임의 SVG 정상 입력, 잘못된 viewBox/접근성/중복 ID/실행 요소, 없는 파일, 혼합 배치의 종료 상태 확인.
- `test_concept_learning.py`: 기존 회귀 24건 통과. 다른 스킬 내용 변경 없음.
- 번들 `quick_validate.py`: 두 원본 스킬 형식 통과. 공식 skills-ref는 원격 CI에서 별도 검증한다.

## 한계

Chromium으로 3개 SVG × 2테마 × 2폭을 렌더링하려고 했지만 프로세스 시작 단계에서 Unix socket 권한 오류로 종료됐다. 스크린샷 생성·육안 렌더링 검수는 완료하지 못했다. 기존 도형 좌표는 바꾸지 않았으며 이번 TCP 변경은 메타데이터 교정이다. 실제 Reader/Obsidian 통합, 클립보드 복사, Codex/Claude 설치 및 종단 호출은 미검증이다. 정적 검사나 과거 PR의 브라우저 통과를 해당 검증으로 대체하지 않는다.
